CRYSTAL POOLS — HOW TO REPLACE WEBSITE IMAGES
===============================================

Drop your photos into the folders below. Keep the EXACT filenames.
The website will update automatically — no developer needed.

IMPORTANT: Use .jpg for photos, .png only if you need transparency.
           You can drop any common format (.jpg, .png, .webp) — the
           website will find it automatically by filename.

    gallery-09.jpg  ← Gallery photo 9  (tall tile)

  dark/               ← Same filenames — photos shown in DARK mode
    gallery-01.jpg … gallery-10.jpg

  1200×900 or higher as they occupy larger grid cells.
  If you only have one set of photos, put the same images in both folders.
